# Field Pivot

Kiosk, ATM, and locker field work. 3D-printed service parts. Tinkerer.

**Field Pivot, Inc.** — Southeast U.S., remote national  
[fieldpivot.com](https://fieldpivot.com) · (877) 707-2307

This account is a shop notebook, not a software portfolio. What lives here is what gets used on a job: printable parts, install notes, and honest pointers to other people's work when that work is the source of truth.

## Working repos

- **[parts](https://github.com/cryptopivot/parts)** — replacement parts and jigs we model and print. Files we designed. Credit on anything we did not.
- **[field-ops](https://github.com/cryptopivot/field-ops)** — survey and install notes in our own words. Checklists to build on, not a finished manual.
- **[FieldRB](https://github.com/cryptopivot/FieldRB)** — personal mirror of [unredbox/Wiki](https://github.com/unredbox/Wiki) / [redbox.wiki](https://redbox.wiki). They wrote it. We keep a copy for field use.

## How this is meant to work

Improve a thing if it serves a purpose. Do not republish someone else's project as ours. Client sites, keys, and live payment paths stay off the public repos.

If a printable or a field note helps you, use it. If you improve it, say so and send it back.
